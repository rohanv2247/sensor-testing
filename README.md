# sensor-testing
we have some cool sensors which can be used in many normal to professional ways. This is just a demo of how the sensor works when we connect it to an Arduino board and code it on how we want to make it work

📌 Project Overview
This repository contains code and documentation for testing various sensors using an Arduino Uno and a breadboard setup. The goal is to demonstrate sensor interfacing, data collection, and basic Arduino programming.

⚙️ Hardware Used
Arduino Uno
Breadboard
Jumper wires
Sensors tested (list them here, e.g.):
DHT11/DHT22 (Temperature & Humidity)
Ultrasonic Sensor (HC-SR04)
LDR (Light Dependent Resistor)
IR Sensor



💻 Software Requirements
Arduino IDE (latest version recommended)
Required libraries (mention if you used any, e.g. DHT.h, LiquidCrystal.h)

🚀 Setup Instructions
Connect the Arduino Uno to your PC via USB.
Assemble the circuit on the breadboard as per the wiring diagrams (to be added in /docs or /images).
Open the .ino file in Arduino IDE.
Install necessary libraries via Sketch → Include Library → Manage Libraries.
Upload the code to the Arduino Uno.
Open the Serial Monitor to view sensor readings.

📊 Output
Sensor readings are displayed on the Serial Monitor.
Example:
Code
Temperature: 28°C
Humidity: 65%
Distance: 12 cm
Light Intensity: 320
